## Android 播放设置与平台替代

- SurfaceView/TextureView：Android 渲染后端概念；当前使用 AVKit/AVPlayerLayer，不暴露无效的 Android 选项。比例、裁剪等用户可见效果仍需单独实现。
- 硬/软解码：AVPlayer 没有与 Android FFmpeg 扩展相同的强制软件解码开关；额外内核审计和集成尚未完成。
- Anime4K/画面增强：Android Media3 效果链不能直接链接；需原生 Metal/Core Image 或经过审计的替代方案，当前未实现。
- 内核预热、隧道播放、优先 AAC：存在 Android 播放器/AudioTrack 特定语义；尚未逐项评估可见收益与替代，不能假装设置已经生效。
- 后台播放开关、退出 PiP 策略、音乐页：后台音频基础会话已接，原版完整开关/退出策略和音乐页未完成。
- 下一集预加载、预加载时长、磁盘播放缓存和容量：当前 URLCache 清理不能替代它们。

将来每一项都应分别记录“代码已接线 / 受控媒体验证 / 用户源验证 / 真机验证”。系统提供部分能力，不足以将整个 Android 行为标为完成。
