## 本轮新增与修复

- 原版四枚导航图标、中央直播按钮、首页猫咪图案与浮动导航尺寸；详情隐藏底栏。
- M3U/TXT 和内联直播频道、分组搜索、频道/线路切换；XMLTV/JSON 节目单、日期与午夜处理、缓存和错误状态。
- 同 key / 同视频 ID 的不同 API 或扩展源不再互相覆盖历史/追剧。
- 对照 Android 忽略非对象 header，并清理 API 地址首尾空白。
- 包检查检测 arm64 / iOS device 可执行文件、bundle ID、测试资源排除、版本和源码提交号；修复 XcodeGen 默认展示版本问题。
- 单独记录播放器未实现操作、现有二进制 SHA256、工作流隔离及自行签名步骤。

## 已知的验证范围

最近成功的 a2a4ef73 构建包括 54 项核心测试、普通配置导入到网页解析/媒体代理/AVPlayer 点播、受控直播频道和节目单网络读取、模拟器/设备编译和 IPA 打包。测试视频由 CI 自产并只属于测试 bundle，生产 App 没有测试媒体或默认影视源。

header/API 兼容、UTC+8 节目单时间、原生海报加载及尺寸限制、毛玻璃导航和原生音轨/字幕选择已通过后续独立构建。SRT/WebVTT 导入、播放器叠加及偏移已提交 10b2b4e2，当前等待其独立编译测试；文件导入、全屏外部字幕仍未完成端到端验收。毛玻璃已有真实背景模糊、表面着色和边缘高光，Android 折射/色散效果尚未等价实现。

这些结果不等于真实用户影视源全覆盖、长时间直播稳定性、全部格式支持、PiP/AirPlay/后台/锁屏/相机真机验收。详见 FEATURE_MATRIX.md、PLAYER_PARITY.md、AUDIT.md 和 SIGNING_WINDOWS.md。
